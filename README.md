# 造船所向け 船体ブロック進捗管理システム (Shipyard Block Progress Management)

造船現場における船体ブロックの製造・塗装・組立の進捗状況をリアルタイムで把握し、現場のボトルネックを可視化するためのWebアプリケーションシステムです。

## 📌 システム概要

本システムは、VB.NET (ASP.NET Core Minimal APIs) と SQLite を用いた軽量かつ堅牢なバックエンドと、Vanilla JavaScript による動的なフロントエンドで構成されています。複数ユーザーによる同時更新時のコンフリクト防止（楽観的ロック）や、操作履歴の非同期監査ログ記録など、実務に耐えうる堅牢な設計を取り入れています。

## 🚀 主な機能・特徴

1. **ブロック一覧表示 & ステータス動的更新**
   - 船体ブロックごとの工程・重量・現在の進捗ステータス（未着手〜完成）を一元管理。
2. **楽観的ロック（排他制御）**
   - 複数ユーザーによる同時編集時のデータ競合を検出し、409 Conflict エラーで安全に衝突を防止。
3. **進捗集計・ボトルネック分析 API**
   - 全ブロックの総数・総重量の集計に加え、進捗の滞留している（ボトルネックとなっている）工程を自動特定。
4. **非同期監査ログ（AuditLogs）**
   - ステータス変更などの主要な操作履歴を非同期処理でバックグラウンド記録。
5. **パフォーマンス最適化**
   - アプリ起動時のDB初期化と同時に、検索・集計頻度の高い列に対するSQLiteインデックスを自動生成。

## 🛠 使用技術 (Tech Stack)

- **Backend:** VB.NET (.NET 8 / ASP.NET Core Minimal APIs)
- **Database:** SQLite (Microsoft.Data.Sqlite)
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (Fetch API)
- **Version Control:** Git / GitHub

## ⚙️ 動作確認手順 (Getting Started)

1. リポジトリをクローンまたはダウンロードします。
2. ターミナルでプロジェクトルートを開き、以下のコマンドを実行してサーバーを起動します。
   ```bash
   dotnet run
   ```
